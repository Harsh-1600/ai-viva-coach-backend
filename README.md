## 🚀 Key Features

1. **🎙️ Speech & Voice-Driven Viva Simulation:**
   - Real-time speech recognition (Speech-to-Text).
   - Voice or text response options with session countdown timers.
   - Consecutive question progression without interruptions.

2. **📊 100-Point Rubric Evaluation Report:**
   - Technical Accuracy, Conceptual Clarity, Communication, and Depth.
   - Subject-wise strength breakdown and critical improvement areas.
   - Printable and exportable PDF student dossier.

3. **👩‍🏫 Educator Management System:**
   - Class analytics and student progress tracking.
   - Homework/task assignment with deadlines and priority levels.
   - Review and grading workflow with student submission tracking.

4. **🤖 AI Doubt Clearing Assistant:**
   - Context-aware chatbot explaining missed concepts, model answers, and next steps.
